## 二、数据说明

- **来源**：新疆储能电站 BMS（电池管理系统）监控数据
- **规模**：25590 行 × 79 列，时间跨度 2025-02 ~ 2026-06（每 5 分钟一条）
- **核心字段**：
  | 字段 | 含义 |
  |---|---|
  | voltage | 电池簇总电压（~795V） |
  | current | 电流（充正放负） |
  | temper | 温度 |
  | soc | 荷电状态（标签） |
  | soh / remain_capacity | 健康状态 / 剩余容量 |

## 三、V1 全过程与核心结论

### 阶段 1：环境搭建与数据读取（第 1~2 周）

- 建立 Python 虚拟环境，安装 numpy / pandas / matplotlib / scikit-learn
- 建 GitHub 仓库，git 走 socks5 代理
- **核心结论**：环境是一切的基础，真实数据列多、格式杂，先用假数据练工具、再用真数据做分析

### 阶段 2：EDA 探索性分析（pandas）

用 pandas 读入真实 BMS 数据，逐步摸清：

| 发现 | 结论 |
|---|---|
| 79 列中 30+ 列全空 | BMS 协议预留字段未上报，剔除 |
| SOC 有 68% 时间卡在 82.6 | 电站长期待机，标签极不均衡 |
| 按电流划分状态：待机占 97.2% | 有效充放电样本仅 ~700 行（16 个月） |
| soc 与 soe 完全同步 | soe 是 soc 复制列，无额外信息 |
| cycle_time_module 只有 1/24 两值 | 非循环计数，是设备编号 |
| 充放电时温度高于待机 ~1.4℃ | 数据自洽，物理规律成立 |

- **核心结论**：**数据本身干净（无缺失/溢出），但标签变化太少 → 不适合直接做连续 SOC 回归，需换开源数据集（NASA PCoE / CALCE）**&#8203;

### 阶段 3：可视化（matplotlib）

- 画 SOC/电压/温度时序曲线 + 分布直方图
- 配置中文字体（`SimHei`）
- **核心结论**：直方图在 82.6 处一根超高柱子，直观坐实「标签分布极度不均衡」

### 阶段 4：特征工程 + 数据集划分

- 确定特征 X（voltage/current/temper）、标签 y（soc）
- 训练集/测试集 8:2 划分，`shuffle` 打乱
- **核心结论**：特征工程 = 定 X 定 y；划分目的是用「没见过的数据」检验泛化能力

### 阶段 5：第一个 baseline（线性回归）

- `LinearRegression().fit()` 训练，MAE/RMSE 评估
- **结果**：MAE = 11.93，RMSE = 18.46
- **核心结论**：误差很大（SOC 量程 0~100 错 12 点不可用），但**误差不会随数据增多无限趋近 0**，上限由特征信息量决定

### 阶段 6：过拟合诊断

| 实验 | 结果 | 结论 |
|---|---|---|
| 训练/测试对比 | 11.88 vs 11.93 | **无过拟合** |
| Ridge 正则化 (alpha=0.1/1/10) | 均 11.93 | 无效 → 确认误差非过拟合 |
| 5 折交叉验证 | 7.4 ~ 35.4 | **分布漂移**（不同时段 SOC 停留值不同） |

- **核心结论**：误差来自「偏差（模型太简单）+ 数据问题（标签不均衡/漂移）」，**不是过拟合**

### 阶段 7：baseline 调优（特征 + 非线性）

| 实验 | 改动 | MAE | 结论 |
|---|---|---|---|
| A | 仅电压 | 12.38 | 单特征信息不足 |
| B | 电压+电流+温度 | 11.93 | baseline 水平 |
| C | +remain_capacity | **0.000** | ⚠️ **数据泄漏** |
| D | 换随机森林 | **1.08** | 非线性 >> 线性（11 倍） |

- **核心结论 1（数据泄漏）**&#8203;：`remain_capacity` 与 SOC 是恒等关系（SOC = 剩余容量/总容量），等于把答案喂给模型。**选特征前必须问：预测时这个特征在真实场景拿得到吗？**
- **核心结论 2（非线性价值）**&#8203;：同样特征，随机森林比线性回归误差降 11 倍 → SOC-电压关系本是非线性，为 V2 换神经网络提供实证

---

### 阶段 8：树模型进阶 + 调参

**特征重要性**（随机森林 `feature_importances_`）：

| 特征 | 重要性 | 解读 |
|---|---|---|
| voltage | 0.836 | SOC 与电压强相关，主力特征 |
| temper | 0.106 | 充电发热、季节效应 |
| current | 0.058 | 75% 为 0（待机），废特征，坐实 EDA 判断 |

**树数量扫描**：10~200 棵，MAE 1.083 → 1.079，100 棵已饱和，误差地板由数据决定。

**Boosting 对比实验**：

| 模型 | 集成方式 | MAE | 结论 |
|---|---|---|---|
| 随机森林 | bagging（并行投票） | 1.080 | 对噪声鲁棒 |
| GBDT | boosting（串行纠错） | 2.577 | 被坏点带偏（拟合残差时异常点放大） |
| XGBoost | boosting + 正则化 | 1.261 | 内置正则化更抗噪 |

**网格搜索调参**：GridSearchCV（3 折）最优 `n_estimators=200, max_depth=None`，测试集 MAE 1.079（默认参数 1.080，收益仅 0.001）。

- **核心结论**：调参空间已榨干，模型侧到上限；瓶颈在数据（待机/坏点/标签不均衡）。V1 模型侧收官，下一步必须换数据源。

## 四、踩坑记录（面试可讲的故事）

1. **数据泄漏**：MAE=0 不是喜报，是警报
2. **分布漂移**：时序数据不能随机打乱切分（交叉验证用 TimeSeriesSplit）
3. **全空列**：describe 全 NaN 不代表数据脏，是列本身没数据
4. **git 历史重写**：单人仓库才用 `push --force`，团队禁用
